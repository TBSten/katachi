# Installing katachi

This page exists so that `<base-url>/install/` is not a dead end. The instructions
themselves are per language.

- **English** — https://tbsten.github.io/katachi/install/en/index.md
- **日本語** — https://tbsten.github.io/katachi/install/ja/index.md

Both drive the same script, which is shared:

```
https://tbsten.github.io/katachi/install/katachi-install.sh
```

The language only decides which checklist and report templates get fetched. Pass it once:

```sh
sh katachi-install.sh init --lang en   # or --lang ja
```

Docs: https://tbsten.github.io/katachi/
