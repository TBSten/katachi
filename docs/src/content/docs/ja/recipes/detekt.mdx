detekt は YAML の設定ファイルでルールの有効・無効やしきい値の設定が可能です。

アーキテクチャ定義に設定ファイルとベースラインを書いて katachi に伝えるべきです。

```kt collapse
// ProjectArchitecture.kt
import me.tbsten.katachi.dsl.architecture

val projectArchitecture = architecture {
    "Tools".group {
        detekt()
    }
}

// roles/Detekt.kt
import me.tbsten.katachi.dsl.DeclarationContainerScope

fun DeclarationContainerScope.detekt() =
    "Detekt".group {
        "Config" {
            layout {
                "config/detekt/*.yml".file()
            }
        }

        "Baseline" {
            layout {
                "config/detekt/baseline.xml".file().optional()
            }
        }
    }
```
