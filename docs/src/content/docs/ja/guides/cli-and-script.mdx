katachi には CLI と kotlin-script 用パッケージが用意されています。
これらを活用することで、AI Agent により厳密に従わせたり、アーキテクチャの変更を自動化して、より機械的に確実な方法でアーキテクチャの運用を支援することを可能にします。

## ユースケース

- katachi を AI Agent にセットアップさせる
  - [初めての定義](../../get-started/first-architecture/) でも katachi CLI を利用するよう案内されています。
- アーキテクチャの変更を自動化する
  - ボイラープレートを自動生成します。

## インストール

katachi CLI は Homebrew でインストールできます。

```bash
brew install tbsten/tap/katachi
katachi --version
```

katachi のバージョンと CLI のバージョンは同じです。`*.katachi.kts` を実行するときは、CLI と同じバージョンの `katachi-script` がスクリプトから使われます。
