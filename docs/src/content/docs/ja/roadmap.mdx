## katachi の現在地

katachi は現在 当初設計された必要となるであろう機能の大部分の実装を終え、作者である [TBSten](https://github.com/TBSten/) が関わるプロジェクトで採用され始めています。

ツールは実際のプロジェクトで使われ フィードバックを受けることで、真に実用性のあるツールに成長します。katachi にはまだその点で非常に未熟であり、実際のプロジェクトで使ったユーザからのたくさんのフィードバックを必要としています。

ぜひ、あなたのプロジェクトで katachi を使ってみてください！

- 実際に使ってみて感じたメリット・デメリット・感想 などとともに [showcase 追加のリクエスト](https://github.com/TBSten/katachi/issues/new?template=showcase_request.yml) をお寄せください！あなたのプロジェクトがこのサイトに乗るチャンスです！
- katachi の [バグ](https://github.com/TBSten/katachi/issues/new?template=bug_report.yml)、[改善点や機能リクエスト](https://github.com/TBSten/katachi/issues/new?template=feature_request.yml) を発見した場合はレポートしてください！

いずれも [GitHub issues](https://github.com/TBSten/katachi/issues) で受け付けています。
