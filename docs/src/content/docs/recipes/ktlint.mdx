ktlint lets you configure things like disabling lint rules through the .editorconfig file.

You should declare .editorconfig in your architecture definition so katachi knows about it.

```kt collapse
// ProjectArchitecture.kt
import me.tbsten.katachi.dsl.architecture

val projectArchitecture = architecture {
    "Tools".group {
        ktlint()
    }
}

// roles/Ktlint.kt
import me.tbsten.katachi.dsl.DeclarationContainerScope

fun DeclarationContainerScope.ktlint() =
    "Ktlint".group {
        "EditorConfig" {
            layout {
                "**/.editorconfig".file()
            }
        }

        "Baseline" {
            layout {
                "ktlint-baseline.xml".file().optional()
            }
        }
    }
```
