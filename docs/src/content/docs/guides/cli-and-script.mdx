katachi comes with a CLI and a package for kotlin-script.
With them, you can make AI Agents follow your rules more strictly. You can also automate architecture changes. This helps you run your architecture in a more mechanical and reliable way.

## Use cases

- Let an AI Agent set up katachi
  - [Your first definition](../../get-started/first-architecture/) also tells you to use the katachi CLI.
- Automate architecture changes
  - Generate boilerplate automatically.

## Installation

You can install the katachi CLI with Homebrew.

```bash
brew install tbsten/tap/katachi
katachi --version
```

The katachi version and the CLI version are the same. When you run a `*.katachi.kts` file, the script uses the `katachi-script` with the same version as the CLI.
