The katachi CLI (`katachi`) is a command-line tool made so that you can leave the setup and operation of katachi to an AI Agent.

## Installation

You can install the katachi CLI with Homebrew.

```bash
brew install tbsten/tap/katachi
katachi --version
```

## Command list

| Command | Description |
|---| --- |
| [`doctor`](#doctor) | Checks that the environment katachi uses is ready. |
| [`scaffold`](#scaffold) | Adds a module for architecture tests (`architecture-test`). |
| [`agent`](#agent) | Subcommands for AI Agents.  |

## doctor

Checks that the environment needed to use katachi is ready.

```shell
katachi doctor
```

<details>
  <summary> Example output </summary>

  ```
  Everything this needs is available (katachi 0.4.0).
     Gradle's JDK: 17 (JAVA_HOME (/Users/you/.sdkman/candidates/java/17.0.17-tem))
     Kotlin: 2.4.10
  ```

</details>

It checks the following:

- [ ] The version of the JDK that Gradle uses
- [ ] The Kotlin version of the project
- [ ] Git

By default, it creates the `:architecture-test` module with this layout.

```
architecture-test/
├── .gitignore                       # /build (only when build/ is not ignored yet)
├── build.gradle.kts
└── src/test/kotlin/com/example/app/test/architecture/
    ├── ProjectArchitecture.kt       # write architecture { } here
    └── ProjectArchitectureTest.kt   # a test that checks the code follows the definition
```

You can customize it with the following options.

### `scaffold --dry-run`

With the `--dry-run` option, you can see which files would be created, without actually creating them.

## agent

The `agent` command is a group of subcommands for AI Agents.

For details of the `agent` command, run `katachi agent --help`.

## Summary

- `katachi` is a command-line tool that you install with Homebrew. It has the same version as katachi.
- `doctor` checks that the Gradle JDK, the Kotlin version, and Git are ready.
- `scaffold --package <package>` creates the check module `:architecture-test` and adds it to the build. With `--dry-run`, you can check the content first.
- An AI Agent uses the subcommands under `agent` while following the setup guide.
