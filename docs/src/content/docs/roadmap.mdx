## Where katachi stands now

katachi has finished implementing most of the features its original design considered necessary, and is starting to be adopted in projects that its author, [TBSten](https://github.com/TBSten/), works on.

A tool grows into something truly practical by being used in real projects and getting feedback. In that respect katachi is still very immature, and it needs a lot of feedback from users who have used it in real projects.

Please try katachi in your project!

- Send us a [showcase request](https://github.com/TBSten/katachi/issues/new?template=showcase_request.yml), together with the benefits, drawbacks and impressions you had from actually using it. It is a chance for your project to appear on this site!
- If you find a [bug](https://github.com/TBSten/katachi/issues/new?template=bug_report.yml), or an [improvement or feature request](https://github.com/TBSten/katachi/issues/new?template=feature_request.yml), please report it!

Both are accepted on [GitHub issues](https://github.com/TBSten/katachi/issues).
