## 3. Write the architecture { } definition

**This is a step where you make the judgment calls.**

Write the `architecture { }` definition based on the information given to you in the prompt by the user and what you investigated in step 1.

**Do not write, tidy up and add constraints at the same time.** In 3-2, first write a definition that says where files go, runs, and save its check result; in 3-3, tidy it up without changing that result (splitting files and packages happens here); in 3-4, decide and write the constraints on contents, which is where the result is meant to change.
