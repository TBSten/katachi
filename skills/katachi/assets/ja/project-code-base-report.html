4. 要素（Role 候補）

group の中に Role が入れ子で並びます。1 つの Role は 1 種類のファイルで、モジュールや層のように種類の違うファイルのまとまりは group です。同じ group の中は重要度の高い順（5 = 必ず定義に入れる / 1 = 入れなくてもよい）。行をクリックすると詳細が開きます。

6. katachi の対象外にするもの

katachi は .gitignore で除外されたファイルを見ません。ここに並ぶのは、git が追跡している（または未追跡で ignore されていない）のに検査から外すものです。

7. ユーザに確認したいこと

選択肢を選ぶか、自由に書いてください（両方あれば自由記入は補足）。答え終えたら下の「回答をコピー」で、AI エージェントとのチャットにそのまま貼れる文がコピーされます。ファイルで渡すときは「JSON を保存」。入力はこのブラウザに下書きとして残ります。

8. テンプレートの提案

同じ形のファイルが何本もある Role に、.template { } を当てる提案です。導入の最後に AI エージェントが記録します。任意です。
