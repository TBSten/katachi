KATACHI-102スクリプトから docs・雛形も生成する

.kts で検査だけ回せても、ドキュメント生成とテンプレートからの生成は Gradle のタスク頼みのまま

今（.kts のスタンドアロン実行ができた場合）
$ katachi check architecture.katachi.kts      // 検査は回る（KATACHI-101 の案）$ katachi docs ...      // 無い。./gradlew katachiDocs だけ$ katachi template ...  // 無い。./gradlew katachiTemplate だけ
案
$ katachi docs architecture.katachi.kts --out docs/architecture$ katachi template architecture.katachi.kts --arg template=Screen --arg feature=home// processor を Gradle の外で回す。KATACHI-101 に従属
リスク・デメリット
  • 利用者Gradle の processors { args { } } と CLI の引数で同じ設定を 2 通りに書く
  • ライブラリprocessor の実行環境（作業ディレクトリ・出力先・gitTracked の基準）を Gradle の外でも同じに保つ。CLI のサブコマンドが増えて保守する面が広がる
