PR で alloc/op の比較表が出るようにした

bench-jmh の 2 つ目の比較が毎回エラーで、確保量の比較がサマリに出ていなかった。

Before
時間を比較手元の gh-pages に
コミットが 1 つ残る
→
alloc/op を比較 ✗fetch gh-pages:gh-pages
non-fast-forward で拒否
After
時間を比較手元の gh-pages に
コミットが 1 つ残る
→
手元の gh-pages を消す追加した 1 ステップ
→
alloc/op を比較 ✓取り直して
比較表が出る
なぜ残るか: github-action-benchmark は auto-push: false でも手元にはコミットする（push しないだけ）。save-data-file: false は gh-pages の経路では見られない。
