p9konsist・konture名前の無い konsist { }・konture { } を同じ Role に 2 つ置くと、baseline が新しい違反を黙って許す

baseline は「規則・パス・Role・制約の名前・宣言」で違反を覚えます。名前の無いブロックは制約の名前が空なので、同じ Role に 2 つ（同じ名前を付けた 2 つでも）あると、片方で記録した違反がもう片方の新しい違反を許し、test は緑のままです。

決めてほしい

詳細
  • (a) で書き換えが要る人: 同じ Role に名前の無い同じ種類のブロックを 2 つ以上書いていた人（名前を付ける）。baseline の鍵が変わるので、上げたら baseline を 1 回取り直す（下の宣言名の件と同じ Migration の 1 行にまとめる）
  • 再現: 名前の無い konture { } 2 つで、1 つ目の違反を baseline に記録 → 1 つ目を直して 2 つ目に違反させる → held back で PASSED、[StaleBaselineEntry] も出ない。違う名前を付けると FAILED（対照）
  • 名前の無い ktFileContent は "ktFileContent" という名前を持ち、1 つしか書けないので起きない
  • 出どころ: exploratory-konsist-konture-r2.md の 1 件目
p9konture* の import が 2 つあるファイルで、依存の規則が Role の外のクラスへの依存を見落とす

import …data.* と import …domain.* があるファイルで UserRepository を使うと、katachi は Role のファイルだけで型を探すので解決できず、functions { }・properties { } の notDependOnPackages と classes { } の notReferenceClass が緑になります。Konture 単体では違反です。

決めてほしい

詳細
  • IntelliJ の既定は「同じパッケージから 5 つ以上で *」なので、* の import が 2 つのファイルは珍しくない
  • classes { }・files { } の notDependOnPackages は import の行そのものを数えるので気づく。KDoc は見落とす側の functions { }・notReferenceClass を「何も落とさない形」として勧めている
  • (a) は検査の時間が増える。どれだけ増えるかは直しの中で測って PR に書く
  • 出どころ: exploratory-konsist-konture-r2.md の 2 件目
p9konsist・konture違反の宣言名がクラスで修飾されず、同じファイルの User.id と Order.id が baseline で同じものとして数えられる

konture・konsist は違反を id・State のようにクラス名を付けずに覚えるので、片方を直して片方を壊すと、新しい違反が黙って許されます。同じ規則を ktFileContent で書くと User.id と覚えて分かれます。

決めてほしい

詳細
  • 起きる形: 1 ファイルに並べたモデルの id・name、画面ごとの入れ子の State・Loading、同じファイルの invoke
  • (a) の移行: 古い記録は stale になり、test は [StaleBaselineEntry] で落ちる（黙っては通らない）。上げる前に test が緑なのを確かめ、上げたら -Dkatachi.baseline.update=true を 1 回
  • konsist・konture・baseline はどれも 0.3.0 からあるので、上げる人の書き換えになる
  • 出どころ: exploratory-konsist-konture-r2.md の 3 件目
p7konturethat() の打ち間違いで何も選ばれないと、katachi でだけ緑になる

katachi は konture の規則に必ず allowEmpty() を付けるので、haveNameEndingWith("ViewModl") のような打ち間違いが黙って通ります。Konture 単体は「No classes matched the filter criteria in 'that()'」で落とし、katachi では厳しい側に戻す口もありません。

決めてほしい

詳細
  • 今の動きは、Role のファイルがまだ無いときに落とさないため。(a) でもその場合は今までどおり緑
  • (a) で書き換えが要る人: ファイルのある Role で、わざと何も選ばない that() を書いていた人（allowEmpty() を足す）
  • 出どころ: exploratory-konsist-konture-r2.md の 4 件目
