KATACHI-89テンプレートから既存ファイルへ追記する

feature モジュールを生成しても settings.gradle.kts の include は手で足すので、生成直後の Gradle は新モジュールを知らない

今
./gradlew katachiTemplate --arg template=Feature --arg feature=home# feature/home/build.gradle.kts などは生成される# settings.gradle.kts には何も起きない#   → include(":feature:home") を手で書くまで sync で見えない
案（next-draft #22、名前は仮）
"Feature" のテンプレート {  ...  appendTo("settings.gradle.kts") {    """include(":feature:${feature}")"""  }  // 同じ行がすでにあれば足さない}
リスク・デメリット
  • 利用者追記先を間違えると他人のファイルを壊す。追記した行は生成の取り消しでは消えない
  • 利用者重複判定が「同じ行があるか」の文字列一致なので、書式の違う include は二重に入る
  • ライブラリ「生成先は layout から決まる」原則の例外になる。IDE の生成プレビュー（期待ファイル一覧）に「既存ファイルへの差分」を表す形が無く、dry-run・差分表示の設計が要る
