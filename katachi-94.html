KATACHI-94IDE プラグインを Marketplace から入れられるようにする

今は GitHub Releases の zip を落として Install Plugin from Disk で入れる。更新も手で入れ直すので、入れる人・更新する人が減る

今（2026-10-01 の決定: zip だけ）
1. GitHub Releases から katachi-intellij-plugin-<版>.zip を落とす2. Settings > Plugins > ⚙ > Install Plugin from Disk3. 新しい版が出ても IDE は教えてくれない。同じ手順で入れ直す
案
Settings > Plugins > Marketplace で「katachi」を検索して Install新しい版は IDE が更新を知らせる// 出す時期は未定。リリースサイクルの分離（KATACHI-136）と一緒に決める
リスク・デメリット
  • 利用者Marketplace の審査の分だけ新しい版が届くのが遅れる。実験的な機能を広く出すと、壊れたときの影響が大きい
  • ライブラリJetBrains アカウント・署名・審査の運用が増える。広く出すなら IDE 向けの JSON 出力を内部専用に分ける（KATACHI-92）、対応する katachi の版を示す（KATACHI-136）が先に要る
