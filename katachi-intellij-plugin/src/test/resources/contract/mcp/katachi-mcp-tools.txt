== katachi_violations
Lists the violations of the last katachi architecture check, as its SARIF report says. It does not run the check; state is notRun when no report exists yet.
-- input
{
    "type": "object",
    "properties": {
        "path": {
            "type": "string",
            "description": "Only the violations of this file, relative to the project root or absolute."
        },
        "module": {
            "type": "string",
            "description": "Only the violations of this katachi definition module, such as :arch."
        },
        "projectPath": {
            "type": "string",
            "description": " The project path. Pass this value ALWAYS if you are aware of it. It reduces numbers of ambiguous calls. \n In the case you know only the current working directory you can use it as the project path.\n If you're not aware about the project path you can ask user about it."
        }
    },
    "required": [],
    "additionalProperties": false
}
-- output
{

    "properties": {
        "state": {
            "type": "string"
        },
        "readAt": {
