.module { } は消え、モジュールはディレクトリのパスで書く

v0.3 で非推奨にした一式を v0.4 で削除。build.gradle.kts と build/ は gradle() が宣言する。

v0.3（非推奨）

"feature".group {
  "Screen".role {
    layout {
      ":feature:*".module {
        mainSourceSet / kotlin /
          "${wildcard("feature").pascalCase}Screen".ktFile()
      }
      ":".module { "settings.gradle".ktsFile() }
    }
  }
}

v0.4

gradle()
"feature".group {
  "Screen".role {
    layout {
      "feature" / capture("feature") {
        mainSourceSet / kotlin /
          "${capture("feature").pascalCase}Screen".ktFile()
      }
      "settings.gradle".ktsFile()
    }
  }
}

削除した API

  • String.module { }
  • wildcards / wildcard(name)
  • ModulePackage / ModulePackages
  • LayoutScopeInternals (currentModulePath など)
  • ArchitectureScope.moduleResolver
  • checkNoModuleSugar (Gradle task)
